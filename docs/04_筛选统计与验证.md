# 筛选、样例统计与验证

## 使用流程

名称或城市搜索与省份、文化类别、朝代记录、5A 评定截止年份共同组成筛选条件。地图与类别分布使用同一份结果，切换聚合或散点不会取消筛选。重置按钮恢复全部样例，地图视野自动适配当前非空结果。

朝代按原始字段精确匹配，例如“明、清”是一个跨代记录；本版本不提供精确年代换算。评定截止年份表示当前样例中在该年及以前评为 5A 的景区，不是景区创建年份，也不是对当年全部有效 5A 名录的重建。

当前仍是 47 个约 1 km 精度的样例点，统计仅描述样例。完整全国名单、坐标逐条核验、PostGIS、GeoServer 和正式历史时间轴尚未完成。

## 验证入口

需要 Node.js 24；已有依赖继续按锁文件使用。通过 Git Bash 执行 `bash scripts/tests/setup.sh` 安装已有依赖，然后执行 `bash scripts/test.sh`。

逻辑验证覆盖组合筛选、无结果、年份边界、统计合计、HTML 转义、非法类别、错误字段类型、坐标越界、重复编号。随后执行数据校验、TypeScript 检查和 Vite 生产构建。当前 GitHub 凭据缺少 workflow 权限，自动检查配置尚未提交；上述测试可本地复现。

Windows 本地执行 `bash scripts/test-browser.sh`，使用系统 Edge 与 Git Bash，无新增依赖。默认 Git Bash 位于 `D:\Git\bin\bash.exe`，其他路径可设置 `WENGIS_BASH`。测试独占端口 43210，结束后关闭自己启动的进程树。测试覆盖初始化、12 类图例、无 key 的默认底图状态、筛选地图统计联动、空结果提示、重置、散点筛选与移动布局。

日志位于 `logs/`，移动界面测试截图为 `logs/browser-mobile.png`。测试同时点击筛选后的地图点位验证弹窗，退出时按项目路径与端口核验并清理遗留服务。浏览器测试验证本地交互，不保证外部底图服务在所有网络环境下可达。
